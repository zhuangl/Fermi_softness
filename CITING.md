# Citation / 引用要求

**Users of this software or the Fermi-softness method in research, publications,
or scientific presentations must cite the original method paper below.**
Please also identify the software version or Git commit used. Citing the software
repository alone does not replace citing the original paper.

**使用本软件或费米软度方法开展研究、发表论文或进行学术报告时，应引用以下原始方法
论文。** 同时请注明所用软件版本或 Git 提交号；仅引用软件仓库不能代替原始论文。

> B. Huang, L. Xiao, J. Lu, L. Zhuang, “Spatially Resolved Quantification of the
> Surface Reactivity of Solid Catalysts,” *Angewandte Chemie International Edition*
> **2016**, *55* (21), 6239–6243.
> [https://doi.org/10.1002/anie.201601824](https://doi.org/10.1002/anie.201601824)
