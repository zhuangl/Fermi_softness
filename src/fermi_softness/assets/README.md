# Fermi Softness application icon

The icon is a transparent cutout derived from the author's selected Pt₃Y Studio
screenshot. It is application branding, not a new computed field or reference
plot. The screenshot and numerical data are unchanged.

`fermi-softness.png` is the transparent master. `fermi-softness.icns` contains
macOS icon sizes generated with `sips` and `iconutil`. The built-in image tool,
exact edit prompt and checksums are recorded in `icon-provenance.json`.

图标取自作者选定的 Pt₃Y 界面截图，用于应用标识。透明 PNG 是原始图标，ICNS 为
macOS 多分辨率图标。来源、处理提示词和校验和见 `icon-provenance.json`。
