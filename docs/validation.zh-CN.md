# 验证范围与原稿差异

[English](validation.md) · [使用手册](user-guide.zh-CN.md)

本页对应 v0.2.0 的实际验证记录。软件一致性、物理收敛和原论文复现是三个不同层次。
已有测试结果不能替代新的体系收敛测试，也不能直接证明与原稿一致。

## 已执行的检查

| 项目 | 证据与范围 |
|---|---|
| 科学单元与集成测试 | 本地 51 项通过；覆盖权重、归一化、自旋、Gamma、斜晶胞、单位、Bader、原生导出和示例 |
| 公开真实 WAVECAR 文件 | 6 个有效真实文件案例；含标准、共线、旋量及非整数 ENCUT |
| 独立读取器 | 与 pymatgen 比较所有能带系数；标准/旋量差异为零，Gamma 最大差异 2.93×10⁻⁸ |
| Pt(111) 静态计算 | VASP 6.4.2；3 原子、400 eV、完整 4×4×1 k 网格、48 带、27 步 SCF |
| Pt(111) 直接重建 | 161 个贡献态；四个位置与独立 Fourier 求和差异不超过 1.87×10⁻⁹ eV⁻¹ Å⁻³ |
| Pt(111) 原生密度 | 161 个 VASP 逐态 PARCHG；空间积分与谱求和相对差异 5.60×10⁻⁸ |
| GUI 与图片 | 实际运行 Qt/VTK；旋转、三种模式、场景恢复、PNG/TIFF、透明度、像素和 DPI |
| Fortran | gfortran 12.3 单独编译核心及数值驱动测试通过；不是 VASP 内部集成测试 |

macOS arm64 / Python 3.11 为本地验证环境；Linux VASP 6.4.2 产生原生数据。
GitHub CI 配置覆盖多系统/Python 版本，实际状态以仓库的运行记录为准。

## Pt₃Y 和 Bader

四层 Pt12Y4 使用 PW91、408 eV、6×6×1 网格和 144 带。自由原子最大受力为
0.02908 eV/Å，小于原文 0.05 eV/Å 阈值。95% 电荷包络面上，采样 Pt 位点平均
43.15 keV⁻¹ Å⁻³，Y 位点为 6.145，比值为 7.02。定性的 Pt 高/Y 低反差通过。
数值比较依据现有论文和历史档案进行，最终 DACAPO 软度网格及生成脚本尚未恢复。

原生场积分为 12.7772506167 eV⁻¹，谱求和为 12.7772506575 eV⁻¹，相对差异
3.19×10⁻⁹。Bader 标签与 ACF.dat 积分交叉核对，原子贡献之和守恒；不等高 Gaussian
测试验证边界确实由密度确定，而非简单的最近原子分配。

参考网格从 80×80×320 加密到 160×160×640，原子软度最大相对变化为 0.4352%，
表面层总和变化为 0.0147%。内置 Bader 分区采用加密结果。详细数据见
[Pt₃Y 报告](../results/pt3y-validation.json)、
[网格加密](../results/pt3y-bader-refinement.json)和
[参考密度敏感性](../results/pt3y-bader-reference-check.json)。

## 关键数值与表示差异

Pt(111) 的谱软度为 3.4955965486 eV⁻¹，直接平滑场积分为 1.9817075255 eV⁻¹，
VASP 原生密度积分为 3.4955963530 eV⁻¹。平滑场与原生表示的差异没有被人为重新
归一化消除。逐态原生归一化最大误差为 1.28×10⁻⁶ 个电子。

该小算例验证软件流程，不代表完整的 k 点收敛、吸附能关系或原始 DACAPO 结果。
可公开的几何与参数位于 [Pt 输入目录](../validation/pt111/README.md)，不含 POTCAR。

## 与 2016 原稿的主要差别

| 项目 | 原稿与当前状态 |
|---|---|
| 定义 | 沿用费米函数导数加权、默认 kT=0.4 eV；记录绝对截断约定 |
| 电子结构 | 原稿 DACAPO/超软赝势；现版 VASP/PAW，密度表示不完全相同 |
| Pt₃Y 结构 | 从历史电荷 Cube 恢复后重新弛豫；不能确认就是最终原稿几何 |
| Pt demo | 目前为小型 PBE 验证体系，不是原稿四层 2×2 PW91 Pt 表面 |
| Bader | 相同分区思想和真实算法；原始参考文件及具体命令尚未恢复 |
| 绘图 | 支持 95% 电荷包络面、软度等值面和切片；现用 PyVista/VTK，相机、插值与原始场景不完全对应 |
| 色标 | 支持原图 1–28 keV⁻¹ Å⁻³；当前部分 Pt 数值超过上限，不能靠改色标宣称复现 |
| 原稿其他结果 | MoS₂ 边缘、全金属系列和吸附能关联尚未逐项重现 |

作者本地八页 SI 已找到并核查；Bader 方法已写在正文 Experimental Section。
找到的旧 Pt₃Y 体数据是早期有限差分 Fukui 场，不是最终费米软度场，因此没有将其
替代为论文定量参考。最终 DACAPO 软度网格和生成脚本仍未恢复。

## 仍需扩大验证的内容

- 更多 VASP 版本、操作系统、编译器和图形环境。
- 真实共线磁性体系的原生 PARCHG 完整流程；当前原生真实基准是非磁体系。
- 全电子重建、特定 VASP 版本内的源码集成。
- 一般磁空间群展开和 `vaspwave.h5` 输入。
- 原始数值数据的进一步比较及完整材料系列。

双精度、大端、旧式 Gamma z 半空间和多记录头已用独立生成数据测试，但没有全部
得到真实 VASP 文件的验证。公开样本中的 `WAVECAR.N2.45210` 记录长度与双精度标记
不符，程序拒绝它，不把这个损坏文件当作双精度支持证据。公开文件来源和校验和见
[清单](../validation/public-fixtures.json)。
